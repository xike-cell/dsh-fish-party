# 鱼塘

**这不是插件，是一个网页。** 打开浏览器，输一个地址、填个名字，就能进去玩。

一只鱼在自己电脑上开一间塘，把门牌号（地址）念给别家的鱼——谁打开那个链接谁就能进来坐坐。塘关了，换一个新门牌，明天再开一间。

---

## 跑起来

只有三个文件有用：

| 文件 | 干什么 |
|---|---|
| `server/party_server.py` | 服务端，只用 Python 标准库，不用装任何东西 |
| `server/web/index.html` | 页面（一个 HTML 文件，没有构建步骤） |
| `server/party_token.txt` | 开房口令，本机用 |

```bash
python server/party_server.py
# 浏览器打开 http://127.0.0.1:8770/
```

Python 3.9 以上就行，没有依赖、不用 pip。

## 里面有什么

0.1.0 自带一局「谁是卧底」当**示范**——它不是这个项目的全部，只是拿来让人一眼看懂「几只鱼凑一桌」是什么样。塘里放什么，由开塘的那只鱼定。

- 词库 **100 组**（咖啡/奶茶、毛衣/卫衣……到凉帽/头盔）
- 3～10 人，默认 4 人 1 卧底
- 发言 20 秒、投票 20 秒
- 赛后掀牌、60 秒闲话、再来一局

**两种房间：**

- **公开房**——挂在大厅，谁都能进；不想等人就点「随便进一间」，优先塞进等得最久的房
- **私人房**——不挂出来，凭「房号 + 四位口令」进。约人的时候用这个，不会被人撞进来

**门口：**

- 名字随便填，20 字以内
- B 站号**选填**：填了会替你查昵称、挂在名字后面；不填也能玩
- 懒得想名字，点「随便给我一个」，会随机叫「路过的鱼 3721」

## 给别人玩

默认只监听 `127.0.0.1`，别人打不开。要让外面能进，开一条隧道：

```bash
cloudflared tunnel --url http://127.0.0.1:8770
```

会给一个 `https://xxx.trycloudflare.com`——**每次重启都会变**，这是临时地址。

想要固定地址，得买一个域名、配 Cloudflare 的命名隧道（一年几十块，地址永久）。

---

## 它不需要 DSH

这个项目最早是当 DSH 插件写的，那部分代码（清单、客户端、patch 层）已经全部删掉了——那个形态在目标环境里装不上。

现在它就是一个独立的网页服务：一个 Python 进程 + 一个 HTML 文件，跟 DSH、跟任何插件系统都没有关系。
